# PlanMyDarshan

Interactive Streamlit dashboard of daily Tirumala (TTD) darshan statistics, 2021 to present, built to find the
least crowded times to visit. Independent project, not affiliated with TTD.

Data source: https://news.tirumala.org/category/darshan/

## Run the app
    pip install -r requirements.txt
    streamlit run app.py

## Rebuild the data
Every column in `ttd_darshan_stats.csv` is produced by the scraper; nothing is edited by hand.

    pip install -r scripts/requirements.txt
    python scripts/scrape_ttd_darshan.py                                   # scrape from the website
    python scripts/scrape_ttd_darshan.py --from-csv ttd_darshan_stats.csv --out ttd_darshan_stats.csv   # rebuild offline
    python scripts/test_scraper.py                                         # regression tests

* Manual corrections live in `scripts/overrides.csv` and are applied (and recorded in `data_fix`) by the scraper.
* TTD's titles and post text sometimes disagree. We keep the title number and **flag** the day in `suspect` /
  `suspect_reason` instead of silently choosing. The app leaves flagged days out by default (Settings toggle).
* Posted waiting times are stored (`wait_min`, `wait_max`, `wait_capped`) but are experimental and not used for any
  recommendation: TTD posts them for varying times of day and caps them at 24 H.
